## Lokal körning

Projektet består av statiska filer och kräver ingen installation.

Klona repositoryt:

```bash
git clone https://github.com/EricaNordlof/ericanordlof.github.io.git
```

Öppna projektmappen:

```bash
cd ericanordlof.github.io
```

Starta exempelvis en lokal server med Python:

```bash
python -m http.server 8000
```

Öppna sedan:

```text
http://localhost:8000
```

Det går också att öppna `index.html` direkt i webbläsaren, men en lokal webbserver rekommenderas för att länkar och resurser ska fungera på samma sätt som i produktion.

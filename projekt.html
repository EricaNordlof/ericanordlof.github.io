Utvalt case · Produktionssystem

Offroad Bumpis Booking

Ett eget boknings- och administrationssystem som används i min uthyrningsverksamhet. Systemet hanterar bokningar, tillgängligt lager, priser, betalningsstatus, rabatter, dokumentflöden och olika regler för barn- och vuxenbollar.

Problemet

Bokningar, lager, priser, kunduppgifter och dokument behöver hanteras i ett gemensamt flöde.

Min lösning

Ett samlat fullstacksystem med bokningsstatus, lagerkontroll, affärsregler och administration.

Vad projektet visar

Att jag kan gå från ett verkligt verksamhetsbehov till datamodell, backend, gränssnitt och produktionsdrift.

Verklig komplexitet

Systemet måste hantera datum, lagertak, olika produkter, prissteg, betalningar och dokument.

Centrala utvecklingsområden: dubbelbokningsskydd, lagerberäkning, datum- och periodregler, barn- och vuxenlager, flerdagarsrabatter, betalningsstatus, avbokning, dokumentgenerering och e-postflöden.
Node.js Express JavaScript REST API Databas Affärsregler PDF Render
